PREDICTIVE MODELING USING MACHINE LEARNING

Project Objective:
The objective of this project is to build a machine learning model that predicts student marks based on study hours.

Tools and Libraries Used:

* Python
* Pandas
* Matplotlib
* Scikit-learn
* VS Code

Tasks Performed:

1. Loaded dataset using Pandas
2. Prepared input and output data
3. Applied Linear Regression algorithm
4. Trained machine learning model
5. Predicted student marks
6. Visualized prediction using regression graph
7. Evaluated model accuracy using R² score

Files Included:

* student_scores.csv
* project.py
* README.txt

Outcome:
Learned the basics of supervised machine learning, predictive modeling, regression analysis, and model evaluation using Python.
